# 📖 ডিজিটাল খতিয়ান - মালামাল ক্রয় রেজিস্টার খাতা (PWA)

আপনার ২৫০ পৃষ্ঠার ম্যানুয়াল মালামাল ক্রয় রেজিস্টার খাতার হুবহু ডিজিটাল রূপ। এটি একটি আধুনিক **PWA (Progressive Web App)**, যা আপনার পিসি (কম্পিউটার), ল্যাপটপ এবং মোবাইল ফোনে সমানভাবে ব্যবহার করা যায়।

---

## 🌐 যেকোনো জায়গায় বসে অনলাইনে ব্যবহার করার নিয়ম (How to Use Online Anywhere)

আপনার খাতাটি আপনি দুটি উপায়ে যেকোনো জায়গায় বসে অনলাইনে মোবাইল বা পিসি থেকে ব্যবহার করতে পারবেন:

### পদ্ধতি ১: আপনার পিসি থেকে সরাসরি ১-ক্লিকে অনলাইন করা (Instant Cloudflare Tunnel)
আপনার কম্পিউটারে ডাটা থাকবে, কিন্তু আপনি যেকোনো স্থান থেকে মোবাইল ডাটা (4G/5G) বা যেকোনো ওয়াইফাই দিয়ে এটি ব্যবহার করতে পারবেন:

1. আপনার ফোল্ডারে থাকা **`run_online.bat`** ফাইলে ডাবল ক্লিক করুন।
2. এটি স্বয়ংক্রিয়ভাবে একটি ফ্রি ও নিরাপদ পাবলিক অনলাইন HTTPS লিংক তৈরি করে দেবে (যেমন: `https://xxxx.trycloudflare.com`)।
3. স্ক্রিনে আসা **QR কোডটি মোবাইলের ক্যামেরা দিয়ে স্ক্যান করুন** অথবা লিংকটি আপনার মোবাইলের Chrome বা Safari ব্রাউজারে খুলুন।
4. ব্যস! এখন আপনি দোকানে বা বাজারে বা যেকোনো জায়গায় বসে মোবাইলেই এন্ট্রি দিতে পারবেন এবং দেখতে পারবেন। সব এন্ট্রি সরাসরি আপনার খাতার ডাটাবেজে জমা হবে।

---

### পদ্ধতি ২: ক্লাউডে ২৪/৭ হোস্ট করা (পিসি বন্ধ থাকলেও অনলাইনে চলবে - Render.com)
আপনি যদি চান আপনার কম্পিউটার বন্ধ থাকলেও খাতাটি ইন্টারনেটে ২৪ ঘণ্টা লাইভ থাকবে এবং যেকোনো সময় যেকোনো মোবাইল বা কম্পিউটার থেকে ব্যবহার করা যাবে, তবে এটি **Render.com** এ সম্পূর্ণ বিনামূল্যে হোস্ট করতে পারেন:

1. [GitHub.com](https://github.com) এ একটি ফ্রি একাউন্ট খুলে এই ফোল্ডারের ফাইলগুলো একটি নতুন রিপোজিটরিতে (Repository) আপলোড করুন।
2. [Render.com](https://render.com) এ গিয়ে বিনামূল্যে সাইন ইন করুন।
3. **"New +" -> "Web Service"** সিলেক্ট করুন এবং আপনার গিটহাব রিপোজিটরিটি কানেক্ট করুন।
4. Render স্বয়ংক্রিয়ভাবে সব সেটিংস (`Procfile`, `render.yaml`) ডিটেক্ট করে নেবে:
   - **Environment:** `Python`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn server:app`
5. **"Deploy Web Service"** বাটনে চাপ দিন।
6. মাত্র ২ মিনিটে Render আপনাকে একটি স্থায়ী লিংক দিয়ে দেবে (যেমন: `https://my-khatiyan.onrender.com`)।
7. এই লিংকটি আপনার মোবাইলে খুলে **"Add to Home Screen"** দিলে এটি আজীবনের জন্য একটি ফুল মোবাইল অ্যাপ হয়ে যাবে!

---

## 💻 পিসিতে অফলাইনে চালু করার নিয়ম (Local Offline Run)

1. `run.bat` ফাইলে ডাবল ক্লিক করুন।
2. স্বয়ংক্রিয়ভাবে আপনার ব্রাউজারে `http://localhost:5000` ঠিকানায় রেজিস্টার খাতাটি চালু হয়ে যাবে।

---

## 📱 মোবাইলে অ্যাপ (PWA) হিসেবে ইনস্টল করার নিয়ম:
1. মোবাইলের ব্রাউজারে (Chrome বা Safari) খাতার লিংকটি খুলুন।
2. **Android (Chrome):** ওপরের ৩-ডট মেন্যুতে (⋮) ট্যাপ করে **"Add to Home screen"** / **"Install app"** চাপুন।
3. **iPhone (Safari):** নিচে শেয়ার (Share ⎋) বাটনে ট্যাপ করে **"Add to Home Screen"** চাপুন।
4. আপনার মোবাইলের হোম স্ক্রিনে খাতার একটি আইকন চলে আসবে। এরপর থেকে যখন খুশি যেকোনো জায়গা থেকে এন্ট্রি দিতে পারবেন।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)

* **১ম পৃষ্ঠা: সূচিপত্র (Master Index):** মাদার আইটেম ও পৃষ্ঠা নম্বরের তালিকা।
* **২৫০ পৃষ্ঠা রেজিস্টার ভিউ:** আসল লেজার খাতার মতো লাল মার্জিন রেখা ও রুলটানা টেবিল।
* **স্বয়ংক্রিয় পৃষ্ঠা ও দর ক্যালকুলেশন:** ক্যাটাগরি সিলেক্ট করলেই পৃষ্ঠা বরাদ্দ, পরিমাণ ও দর দিলে মোট টাকা হিসাব।
* **অফিশিয়াল A4 প্রিন্ট:** যেকোনো পৃষ্ঠা বা সূচিপত্র একক ক্লিকে প্রিন্ট বা PDF হিসেবে সেভ করার সুবিধা।
* **এক্সেল ও ব্যাকআপ:** Excel (CSV) ডাউনলোড এবং সম্পূর্ণ খাতার JSON ব্যাকআপ ও রিস্টোর।
